🏦 Bank System Console Application

📖 Описание
Современная консольная банковская система с продвинутыми возможностями управления счетами, комплексной антифрод-защитой и полным аудитом операций. Приложение предоставляет безопасную и надежную платформу для финансовых операций с многоуровневой системой проверок.


🚀 Ключевые возможности
💳 Управление счетами
Создание и закрытие счетов
Пополнение и снятие средств
Межсчетные переводы с автоматическим расчетом комиссий
Автоматическое распределение средств при закрытии счетов


🛡️ Продвинутая антифрод-система
Мониторинг активности: ограничение операций в час
Контроль подозрительных транзакций: отслеживание крупных сумм
Защита от быстрых снятий: ограничение операций снятия в короткие периоды
Система предупреждений: автоматическая эскалация при подозрительной активности
Блокировка счетов: при превышении лимитов нарушений


📊 Аудит и логирование
Полная трассировка всех финансовых операций
Детальное логирование комиссий и комиссионных отчислений
Аудит пользовательских действий
Временные метки и идентификаторы операций


🛠️ Технологический стек
Технология	Назначение
Java 21	Основной язык разработки
Spring Framework	DI, конфигурация, транзакции
Spring JDBC	Работа с реляционной БД
PostgreSQL	Основное хранилище данных
Redis	Кэширование и антифрод-система
JUnit 5 + Mockito	Тестирование и мокирование
SLF4J + Logback	Производительное логирование
Maven	Сборка и управление зависимостями


💻 Доступные команды
Команда	Описание
USER_CREATE	Создание нового пользователя
SHOW_ALL_USERS	Просмотр всех пользователей
ACCOUNT_CREATE	Создание банковского счета
ACCOUNT_CLOSE	Закрытие счета с переводом остатка
ACCOUNT_DEPOSIT	Пополнение счета
ACCOUNT_WITHDRAW	Снятие средств со счета
ACCOUNT_TRANSFER	Перевод между счетами


🛡️ Антифрод-система
Мониторинг активности
Лимит операций: не более 10 операций в час на счет
Контроль предупреждений: блокировка после 3 предупреждений за 7 дней
Крупные операции: отслеживание транзакций свыше 300,000
Быстрые снятия: ограничение - 5 снятий за 5 минут


💰 Система комиссий
Внутренние переводы: между счетами одного пользователя - без комиссии
Внешние переводы: между разными пользователями - комиссия 1.5%
Автоматический расчет: комиссия вычисляется и логируется автоматически


📈 Производительность
Redis кэширование: счетчики операций и предупреждений
Оптимизированные запросы: минимальное количество обращений к БД
Пакетные операции: группировка связанных действий
